# 💼 Portfolio

A modern, full-stack developer portfolio built with **React**, **TypeScript**, **Node.js**, and **Express**.

## ✨ Features

- Responsive UI
- Secure Admin Dashboard
- JWT Authentication
- Dynamic Project Management
- Contact Form
- Cloudinary Image Uploads
- Modern Animations
- Production-ready Architecture

## 🛠 Tech Stack

### Frontend
- React
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Framer Motion
- React Hook Form

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Nodemailer
- Cloudinary

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Sudiptyo/Portfolio.git
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm run dev
```
